# EXPATRIADO — Landing page para GitHub Pages

Plantilla web estática para la marca **EXPATRIADO | Mezcal artesanal de Morelos**.

## Archivos incluidos

- `index.html` — estructura de la página.
- `style.css` — estilos, colores, tipografías y diseño responsive.
- `script.js` — menú móvil, aviso de edad, animaciones y botón de copiar email.
- `assets/` — imágenes del logo y conceptos visuales.
- `.nojekyll` — evita que GitHub Pages procese la web con Jekyll.

## Cómo subirlo a GitHub Pages

1. Crea un repositorio nuevo en GitHub. Ejemplo: `expatriado-mezcal`.
2. Sube todos los archivos de esta carpeta al repositorio.
3. Entra en **Settings > Pages**.
4. En **Build and deployment**, selecciona:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
5. Guarda los cambios.
6. Espera 1-3 minutos. Tu web aparecerá en una URL tipo:
   `https://tuusuario.github.io/expatriado-mezcal/`

## Qué debes cambiar antes de publicarla

Busca en `index.html` las partes marcadas con `CAMBIAR` y revisa:

- Correo de contacto: `contacto@expatriadomezcal.com`
- Texto legal o aviso de consumo responsable.
- Datos definitivos del producto: graduación, lote, precio, formato, etc.
- Imágenes finales de botella/logotipo cuando tengas el diseño definitivo.

## Nota importante

Esta plantilla no vende alcohol online. Es una landing informativa de marca y captación profesional. Para venta directa sería necesario añadir condiciones legales, aviso de edad reforzado, política de privacidad, condiciones de venta, fiscalidad, logística y cumplimiento específico para bebidas alcohólicas.
